# Freight model data

The repository currently contains two data classes:

- `src/data/freightData.ts` and `src/data/sihData.ts`: terminal demo fixtures used by the UI.
- `data/freight_history_demo.csv`: reproducible synthetic training/backtest data generated by `ml/generate_demo_dataset.py`.

The demo history is **not observed SAIL, AIS, Baltic Exchange, broker, port-authority, or other market data**. It exists only to prove the ML pipeline, feature engineering, chronological training, and backtesting flow end-to-end.

## Before production claims

Replace the demo CSV with licensed or approved historical observations. Keep the same feature contract where possible, document the source and update cadence, and rerun both `ml/train_freight_model.py` and `ml/backtest_freight_model.py` before publishing accuracy metrics.

## Feature contract

Required columns are defined in the ML scripts and include freight-rate lags/moving averages, volatility, 7-day momentum, route congestion, vessel supply, transit days, distance, carbon cost, and month seasonality.
